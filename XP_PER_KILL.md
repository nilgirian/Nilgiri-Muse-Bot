# XP per kill — measured from session logs

Method: XP in Nilgiri is awarded at wound stages during combat
("You gain N experience points!"). Each award is attributed to the
next R.I.P. line. Approximate: XP from fled/aborted fights can
contaminate a kill's total (proven once, session 58 — a 251-XP fido
folded in XP from ~5 fled fights). Treat single-kill values as noisy.
Updated after every hunt session.
